REBOOTERA USB
=============

This drive boots Rebootera OS. Restart your computer and choose this USB drive
in the boot menu of your firmware (usually F12, F11, F8 or Esc).

Folders you can use from Windows, macOS or Linux:

  isos/windows   Windows installation images (.iso)
  isos/linux     Linux installation images (.iso)
  isos/tools     Rescue and utility images (.iso, .img, .efi)
  drivers/       Driver packages (folders with .inf files, firmware)
  tools/         Portable tools to use from an installed system
  files/         Your own files

Do not modify the "rebootera" and "ventoy" folders: they contain the system.
To manage this drive from Windows, run "Rebootera Desktop.exe".

USB DE REBOOTERA
================

Este USB arranca Rebootera OS. Reinicia el equipo y elige este USB en el menú
de arranque del firmware (normalmente F12, F11, F8 o Esc).

Carpetas que puedes usar desde Windows, macOS o Linux:

  isos/windows   Imágenes de instalación de Windows (.iso)
  isos/linux     Imágenes de instalación de Linux (.iso)
  isos/tools     Imágenes de rescate y utilidades (.iso, .img, .efi)
  drivers/       Paquetes de drivers (carpetas con archivos .inf, firmware)
  tools/         Herramientas portables para usar desde un sistema instalado
  files/         Tus propios archivos

No modifiques las carpetas "rebootera" y "ventoy": contienen el sistema.
Para gestionar este USB desde Windows, ejecuta "Rebootera Desktop.exe".
